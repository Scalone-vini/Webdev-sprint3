# Jovi Tech — Câmeras (Sprint 3 - React)

Site institucional da Jovi Tech, apresentando as tecnologias de câmeras inteligentes usadas nos smartphones da marca. Projeto migrado de HTML/CSS/JS puro (Sprint 2) para React com Next.js (Sprint 3).

## Tecnologias utilizadas
- Next.js 16 (App Router)
- React 19
- JavaScript (JSX)
- CSS
- Web Storage API (localStorage)

## Como instalar as dependências
Com o Node.js instalado, na raiz do projeto, rode:

npm install

## Como executar o projeto

npm run dev

Depois abra `http://localhost:3000` no navegador.

## Uso de Inteligência Artificial no projeto
A estrutura do projeto e a divisão dos componentes (Header, Slideshow, TechCards, ContactForm, LoginModal, Footer) foram planejadas pela equipe, com base no protótipo já existente da Sprint 2. A partir desse planejamento, utilizamos a IA (Claude, da Anthropic) como apoio na implementação, principalmente para relembrar conceitos de React vistos em aula (componentes, props, hooks) e para agilizar a criação de alguns componentes já definidos, com destaque para os componentes ligados às imagens do slideshow, além de apoio na migração do projeto de Vite para Next.js. Todo o código foi digitado, testado e depurado manualmente por nós, incluindo a correção de diversos erros de sintaxe, importação e configuração de ambiente que surgiram durante o desenvolvimento em diferentes computadores. O projeto não foi gerado integralmente pela IA; as ideias e a estrutura já estavam moldadas pela equipe, e a IA serviu como apoio pontual ao longo da implementação.
